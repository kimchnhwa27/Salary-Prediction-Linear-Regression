# Salary Prediction Linear Regression

A foundational Machine Learning notebook covering supervised vs. unsupervised learning concepts, train-test dataset splitting (80:20), and building a Simple Linear Regression model to predict salaries from years of experience. Evaluated with an $R^2$ score of 0.9543 and regression fit visualization.
